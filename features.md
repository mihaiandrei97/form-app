Feature Roadmap
Notifications

1. Email Notifications - Alert form owner on new submissions (via Resend)
2. Discord Notifications - Webhook-based notifications with rich embeds
   Integrations
3. Webhooks - Send submission data to any URL (Zapier/Make/n8n compatible)
   Data Management
4. CSV Export - Download all submissions for a form
   Spam Protection
5. Honeypot Field - Invisible field that traps bots (auto-generated)
6. reCAPTCHA/Turnstile - User provides their keys, you verify server-side
   Analytics
7. Form Analytics - Submission trends, counts over time per form
   Form Building
8. Form Templates - Pre-built HTML snippets (contact, feedback, waitlist, etc.)
9. Embeddable Form Builder - Visual no-code form builder with embed code output
